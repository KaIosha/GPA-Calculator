# GPA-Calculator
Student GPA


🎓 GPA Calculator
A simple GPA Calculator built with C# and .NET that allows users to calculate their Grade Point Average (GPA) easily by entering their course hours and grades.

📌 Features
✅ Input total required hours
✅ Add subjects with their credit hours and grades
✅ Automatic GPA calculation
✅ User-friendly interface
✅ Restart option to modify entries

🚀 How to Use
1️⃣ Enter the total number of hours you signed up for and click Save.
2️⃣ For each subject, enter its credit hours and grade, then click Save.
3️⃣ Once all subjects are added, a message will appear with the final GPA.
4️⃣ If you made a mistake, click Restart to re-enter your data.

📌 Technologies Used
C#
Windows Forms
